# Vaffi Hair Salon & Aesthetics

Static marketing site for Vaffi Hair Salon & Aesthetics — 501 Danforth Ave, Toronto.

Deployed at **https://vaffisalon.com** via GitHub Pages.

## Pages

- `index.html` — homepage
- `services.html` — full service menu
- `products.html` — product showcase
- `gallery.html` — photo gallery (with lightbox)
- `video.html` — video subpage
- `contact.html` — contact info, hours, form, map

## Structure

```
css/style.css    shared styles (mobile-first)
js/main.js       nav, lightbox, reveal-on-scroll, form, today's hours
CNAME            custom domain for GitHub Pages
```

## Deploy

Any push to `main` redeploys via GitHub Pages.
